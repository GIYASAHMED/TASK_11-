## Project Overview

This project is a simple and modern online Shoe Shopping  Website UI built using HTML5 and raw CSS3.

The website includes:
- Responsive Navigation Bar for every divices
- Hero Section page
- Product Details Page
- Add to Cart page
- Payment gateway page
- Clean Page Layouts
- Modern UI Design

This project was created to practice:
- Website layout structuring
- CSS positioning
- Flex based layouts
- Navigation alignment
- UI design without frameworks
- Responsive layouts

---

# How to Run the Project

## Step 1: Download the Project

Download or clone the project files into your computer.

git clone https://giyasahmed.github.io/TASK_11-/

OR

Download the ZIP file and extract it.

---

## Step 2: Open the Project

Open the project folder in any code editor such as:
- VS Code
- Sublime Text
- Atom

---

## Step 3: Run the Website

Open the `index.html` file in your browser.

You can:
- Double-click the `index.html` file
- OR use the Live Server extension in VS Code
